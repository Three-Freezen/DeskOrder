# DeskOrder

**Desktop organizing and tile beautification, all in one app**

DeskOrder reorganizes your desktop with "zones": drag files, folders and shortcuts into translucent floating zones to sort them, then turn zones into tiles with liquid glass and widgets — a desktop that is both tidy and beautiful.

- Category: Personalization / Utilities
- Requirements: Windows 10 or later (x64), self-contained runtime, no .NET installation needed
- Price: Free, open source under MIT

## Features

**Zone organization — a tidy desktop at last**
Any number of translucent floating zones: drop files in to sort them. Folder mapping keeps zone operations in sync with the original folder; auto-organize routes new files into zones by extension or filename keyword. Three-state switches (show / minimize / fully hide), and double-clicking the desktop toggles everything at once.

**Tile mode — the centerpiece of your desktop**
Turn a zone into a large tile: a single icon, double-click to launch, styled with liquid glass, a background image and rounded corners — build a tile wall of your own.

**Style it your way, one-click presets**
Borders, fills, title bars, background images, materials, animations, layout — everything is adjustable. Save a style you like as a preset card and apply it to other zones, the panel or widgets with one click, no repeated setup.

**Clock, calendar and sticky note widgets**
An analog/digital clock, a calendar with to-do reminders, and a sticky note summoned by a global hotkey — your desktop becomes a workspace.

**Quick panel**
Summon it with a hotkey: all zone cards, file search, and quick new-document / new-folder actions in one panel.

**Files stay where they are**
Icons in a zone are just references to the original files: files are never copied, moved or renamed. Removing an icon only removes the reference — the original file stays untouched.

**Thoughtful details**
Zones live on the desktop layer and never cover app windows; system tray, auto-start, English/Chinese UI, light/dark themes, in-app updates.
